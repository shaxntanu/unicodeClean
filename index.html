Install Unicode Clean in Codex, Claude Code, or another compatible agent. It gives document workflows a consistent final Unicode and whitespace pass, powered by the bundled Python helper and a reviewable change report.

THE MAIN FEATURE

Install the agent skill

One skill folder includes the workflow and Python helper. The same SKILL.md format works across Codex and Claude Code.

Read SKILL.md ↗
01

Codex

Install in your personal skills folder.

git clone --depth 1 https://github.com/shaxntanu/unicodeClean.git ~/.codex/skills/unicode-clean
02

Claude Code

Install as a personal skill.

git clone --depth 1 https://github.com/shaxntanu/unicodeClean.git ~/.claude/skills/unicode-clean

Restart your agent after installing. Project-specific installs can go in .claude/skills/ or the host's configured skills directory.
